# Dashboard DataWareHouseSubViv - Power Bi

![PowerBi](https://github.com/user-attachments/assets/3bb0bb86-82b5-4a66-9b9f-128783be923c)

Este dashboard fue elaborado en Power BI y muestra información sobre los subsidios de vivienda asignados en Colombia entre los años 2003 y 2025. Toda la información proviene de un DataWarehouse, que corresponde a una base de datos que permite analizar la información de forma rápida y ordenada.
Permite ver diferentes gráficos y mapas que ayudan a entender cuántos subsidios se han entregado en todo el país, por año, por departamento y por municipio. También permite ver cómo ha cambiado la asignación de subsidios a lo largo del tiempo y comparar entre regiones.
Además de interactuar con el dashboard, seleccionando filtros, para obtener información más específica con el fin de facilitar la toma de decisiones y el análisis de políticas públicas relacionadas con la vivienda.
